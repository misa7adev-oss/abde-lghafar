دليل إعداد الموقع على GitHub Pages وFirebase Realtime Database
==============================================================

محتويات المشروع:
- index.html: واجهة الموقع العامة.
- admin.html: لوحة الإدارة.
- assets/style.css: التصميم العربي المتجاوب.
- assets/candidate.png: صورة المترشح.
- assets/firebase-config.js: إعدادات الربط بمشروع Firebase.
- assets/app.js: تحميل المحتوى وإرسال رسائل المواطنين.
- assets/admin.js: تسجيل الدخول وإدارة المحتوى والرسائل.
- database.rules.json: قواعد أمان قاعدة البيانات.

أولاً: إعداد Firebase
1) افتح https://console.firebase.google.com وأنشئ مشروعاً جديداً.
2) من إعدادات المشروع > تطبيقاتك، أنشئ تطبيق Web (رمز </>).
3) تم وضع إعدادات مشروعك التي أرسلتها مسبقاً داخل assets/firebase-config.js. راجعها فقط إذا غيّرت مشروع Firebase.
4) تأكد أن Realtime Database مفعّلة وأن عنوانها هو https://abde-lghafar-default-rtdb.firebaseio.com. إذا لم تكن قاعدة البيانات قد أُنشئت بعد، أنشئها في نفس المشروع وتأكد من المنطقة والرابط.
6) من Build > Authentication > Sign-in method فعّل Email/Password.
7) من Authentication > Users أضف حساب المدير بالبريد وكلمة مرور قوية.
8) افتح حساب المدير وانسخ UID.
9) ضع UID في متغير ADMIN_UID داخل assets/firebase-config.js.
10) افتح Realtime Database > Rules، وانسخ database.rules.json إلى المحرر، واستبدل ADMIN_UID_HERE بنفس UID في كل المواضع، ثم اضغط Publish.

ثانياً: رفع الموقع إلى GitHub
1) أنشئ مستودعاً جديداً (Repository) على GitHub.
2) ارفع كل ملفات هذا المجلد إلى جذر المستودع، وليس داخل مجلد فرعي.
3) من Settings > Pages اختر Deploy from a branch.
4) اختر الفرع main والمجلد /(root)، ثم Save.
5) انتظر حتى يظهر رابط الموقع. افتح الرابط واختبر الصفحة.

ثالثاً: تسجيل دخول الإدارة
- افتح رابط موقعك ثم /admin.html
- سجّل الدخول بالبريد وكلمة المرور اللذين أنشأتهما في Firebase Authentication.
- المدير المسموح به هو صاحب UID الذي وضعته في الملف وفي قواعد قاعدة البيانات.

ملاحظات أمان مهمة:
- إعدادات Firebase الخاصة بتطبيق الويب تكون ظاهرة في ملفات الموقع وهذا طبيعي؛ الأمان الحقيقي في Realtime Database Rules وAuthentication.
- لا تضع كلمة مرور أو مفاتيح خدمة خاصة (Service Account) في ملفات GitHub.
- لا تجعل قواعد قاعدة البيانات مفتوحة للقراءة والكتابة للجميع.
- القواعد المرفقة تسمح للزائر بإضافة رسالة فقط، ولا تسمح له بقراءة الرسائل أو تعديل المحتوى.
- هذه نسخة أولية: الأخبار نصية، ولا يوجد رفع صور للأخبار في هذه النسخة.
- اختبر الصلاحيات بحساب زائر غير مسجل، وتأكد أنه لا يستطيع فتح الرسائل أو تعديل المحتوى.
- الموقع تعريفي مستقل، وليس موقعاً رسمياً للبلدية أو جهة انتخابية.
